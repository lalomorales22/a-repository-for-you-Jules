# Fractal Tree Visualization

This application generates a beautiful, randomized fractal tree using Python's `turtle` graphics.

## How to Run

1.  **Navigate to the `visualizations` directory:**
    ```bash
    cd visualizations
    ```
2.  **Run the Python script:**
    ```bash
    python fractal_tree.py
    ```
    A new window will open, and you will see the fractal tree being drawn.

## Requirements

*   Python 3

The `turtle` module comes standard with Python, so no additional installations are necessary.
